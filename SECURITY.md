# Security Policy

## Reporting Security Issues

If you discover a security vulnerability or potential data-handling risk in any script or configuration within this repository, please report it responsibly:

- **Contact**: Reach out directly via email to `amit1092tiwari@gmail.com`.
- **Details**: Please include a clear description of the vulnerability, affected files, and reproducible steps.
- **Response Target**: Reports are reviewed and acknowledged within 48 hours.

Please do not open public issues regarding suspected security vulnerabilities until they have been reviewed and mitigated.
